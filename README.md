# Dominion Books

Multi-page Vite site for Howard Williams’ *Adam’s Lost Dominion*.

## Local

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Deploy to Vercel

1. Import the GitHub repo `LoveThisLife-C/dominionbooks` in [Vercel](https://vercel.com/new).
2. Framework preset: **Vite** (see `vercel.json`).
3. Build command: `npm run build`
4. Output directory: `dist`
5. Deploy.

Clean URLs are enabled (`/book` works alongside `/book.html`).
